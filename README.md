# avenlo-webmcp-experimental-codex

## About the project

Avenlo is an experimental CRM dashboard with WebMCP tools that help stakeholders investigate client, KYC, and transaction issues faster. It brings useful CRM information into one place while respecting user roles and permissions. This version was created specifically for the WebMCP challenge and is intended as a demonstration, not a production release.
